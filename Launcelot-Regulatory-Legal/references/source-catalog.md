# Korean Regulatory Source Catalog

본 카탈로그는 cold-start-interview와 reg-feed-watcher가 공유하는 한국 공식 출처 목록이다. 사용자가 직접 출처를 추가·삭제할 수 있다(customize에서).

각 출처는 (1) 운영기관, (2) URL, (3) 콘텐츠 타입, (4) 변호사 유튜브 대본 검증 관점에서의 중요도, (5) 알려진 접근 방식을 기재한다. 본 카탈로그는 출처가 실재한다는 사실만 명시한다. 각 페이지의 현행 콘텐츠와 최신성은 reg-feed-watcher 실행 시점에 launcelot-lawyer로 확인한다.

## 법령 (조문 변경 감시)

### 국가법령정보센터 (law.go.kr)
- 운영: 법제처
- 콘텐츠: 현행 법령 전문, 개정 이력, 시행일, 부칙
- 변호사 대본 관점 중요도: 최상
- 사용자 대본 검증과 직결되는 법령:
  - 형법 (특히 307, 309, 311, 156, 283, 347, 314, 350)
  - 정보통신망 이용촉진 및 정보보호 등에 관한 법률 (70조)
  - 개인정보 보호법 (71조 등 형사처벌)
  - 변호사법 (특히 23조)
  - 표시·광고의 공정화에 관한 법률
  - 저작권법 (특히 28조)
- 접근 방식: 웹 인터페이스, 일부 Open API 제공. launcelot-lawyer가 우선 사용.

### 국회의안정보시스템 (likms.assembly.go.kr)
- 운영: 대한민국 국회
- 콘텐츠: 의안(법률안) 검색, 심사 진행, 본회의 통과 여부
- 중요도: 상 (개정안 단계에서 사전 인지)
- 활용: 위 법령들의 개정안 발의·소관위 통과 시점을 미리 잡아둠.

## 판례 (해석 변경 감시)

### 대법원 종합법률정보 (glaw.scourt.go.kr)
- 운영: 대법원 법원도서관
- 콘텐츠: 대법원·각급 법원 판례, 결정문 전문, 판시사항 요지
- 중요도: 최상
- 변호사 대본 관점 모니터링 키워드:
  - 명예훼손 / 정통망법상 명예훼손
  - 모욕 (모욕죄)
  - 무고
  - 협박 / 공갈
  - 사기 (특히 사이버 영역)
  - 업무방해
  - 진실성·공익성 항변 (형법 310)
  - 정당행위 (형법 20)
  - 개인정보 보호법 위반
  - 저작권법 28조 인용

### 헌법재판소 (ccourt.go.kr)
- 운영: 헌법재판소
- 콘텐츠: 헌법소원·위헌법률심판 결정
- 중요도: 상 (위 죄목들의 합헌·위헌 판단이 표현범위에 직접 영향)
- 모니터링 대상: 형법 307·311, 정통망법 70 위헌 여부 결정사 변경 시.

## 변호사 직역 규제

### 대한변호사협회 (koreanbar.or.kr)
- 운영: 대한변호사협회
- 콘텐츠: 변호사 광고에 관한 규정, 변호사윤리장전, 광고심의위원회 심의결과·공지
- 중요도: 최상 (직역 규제는 변호사 대본 마케팅의 핵심 리스크)
- 사용자 대본과 직결: 결과 보장 표현, 비교광고, 사건유치 직접 유도, 비변호사 동업, 전문분야 표시.

### 서울지방변호사회 (seoulbar.or.kr)
- 운영: 서울지방변호사회
- 콘텐츠: 회원 공지, 광고 가이드라인 보충, 징계 사례 (공개분)
- 중요도: 중 (지방회 차원의 추가 가이드)
- 사용자가 서울회 소속일 때 추가.

## 광고·표시 규제

### 공정거래위원회 (ftc.go.kr)
- 운영: 공정거래위원회
- 콘텐츠: 표시·광고 심결례, 부당한 표시·광고행위 가이드라인, 비교광고 심사지침
- 중요도: 상 (변호사 광고도 표시광고법 적용 대상)
- 사용자 대본 관점 모니터링: 변호사 사무소 표시광고 관련 심결례.

### 한국인터넷자율정책기구 (KISO) — 정정요청·임시조치 사례
- 운영: KISO
- 콘텐츠: 정통망법 44조의2 임시조치 통계·정책 자료
- 중요도: 중 (게시물 차단·임시조치 동향 파악)

## 개인정보·콘텐츠 관련

### 개인정보보호위원회 (pipc.go.kr)
- 운영: 개인정보보호위원회
- 콘텐츠: 결정·의결, 분쟁조정 사례, 가이드라인
- 중요도: 상 (의뢰인 사건 묘사에서 식별정보 노출 시 직접 적용)

### 한국저작권위원회 (copyright.or.kr)
- 운영: 한국저작권위원회
- 콘텐츠: 저작권법 해설, 사례 DB, 분쟁조정
- 중요도: 중 (판결문·기사·이미지 인용 적정성)

## 본 카탈로그를 사용하는 규칙

1. 본 카탈로그는 출처가 실재한다는 사실만 명시한다.
2. 각 페이지의 현행 콘텐츠와 최신성은 reg-feed-watcher 실행 시점에 launcelot-lawyer를 통해 확인한다.
3. 본 카탈로그의 추가·삭제는 customize 스킬을 통해서만 한다.
4. 사용자가 카탈로그에 없는 출처를 새로 등록하면 그 출처에 대해 자동으로 신뢰등급을 부여하지 않는다. cold-start-interview 또는 customize 흐름에서 "공식 / 준공식 / 민간"으로 사용자에게 명시적으로 분류받는다.
